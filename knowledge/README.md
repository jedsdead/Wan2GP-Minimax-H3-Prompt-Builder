# Knowledge library

Drop `.md` or `.txt` files here (or use **H3 Prompt Generator → Library & settings → Add to library**).

* `knowledge/always/` — sent with every H3 Prompt Generator request: house style, a series bible, recurring character descriptions, banned words.
* anywhere else in `knowledge/` — split into sections by heading and added only when relevant to the request (keyword match), within the token budget.

Markdown headings (`#`, `##` …) make the best sections. Plain notes are split into paragraph groups.
